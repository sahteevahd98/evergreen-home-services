# Evergreen Home Services

Evergreen Home Services is a responsive multi-page website project created to demonstrate front-end web development and basic server-side development skills.

## Features

- Responsive multi-page website
- Bootstrap responsive navigation
- JavaScript service rendering
- JSON API data loading
- jQuery contact form interaction
- SASS/SCSS styling
- PHP server-side JSON endpoint
- Git and GitHub version control

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
- SASS/SCSS
- PHP
- JSON
- Git

## Pages

- Home
- About
- Services
- Contact

## Project Structure
